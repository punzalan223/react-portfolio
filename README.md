# Patwicku - Spotlight portfolio

Next.js and Tailwind implementation of the Tailwind Plus Spotlight portfolio, branded as Patwicku and populated with Patrick Lester M. Punzalan’s current resume, selected project examples, technical skills, research work, Fleetlyf.com work, and provided profile image.

## Run locally

```bash
npm install
npm run dev
```

The site is available at `http://localhost:3000`.
